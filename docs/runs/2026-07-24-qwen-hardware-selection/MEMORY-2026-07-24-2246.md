# Memória de engenharia

- Arquivos GGUF e `mmproj` são portáveis; o backend do llama.cpp é específico
  do sistema operacional e do acelerador.
- Nunca inferir capacidade visual de um nome `Qwen3-*`; exigir explicitamente
  `Qwen3-VL`.
- Modelo e projetor devem ter a mesma quantidade de parâmetros.
- Escolha automática é um gate de segurança de carregamento, não prova de
  desempenho; a calibração física continua sendo a prova de throughput.
- Core e Core Max mantêm IDs estáveis para compatibilidade, mas registram no
  ambiente os nomes/caminhos realmente selecionados.
- Se a escolha manual desaparecer ou deixar de ser compatível, restaurar o modo
  automático em vez de iniciar um runtime condenado a falhar.
- Memória atualizada somente nos artefatos locais do Codex; Archon não utilizado.
