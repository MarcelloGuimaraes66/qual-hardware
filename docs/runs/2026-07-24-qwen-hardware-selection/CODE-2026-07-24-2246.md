# Alterações de código

- Criado seletor puro de Qwen3-VL com parser estrito, pareamento de `mmproj`,
  orçamento de memória, recomendação Core/Core Max e fallback automático.
- O ambiente passou a expor inventário e seleção, mantendo os IDs legados usados
  pelo pipeline e pelos relatórios.
- Adicionado endpoint local validado para escolha automática ou manual; trocas
  continuam bloqueadas enquanto uma calibração está ativa.
- A Verificação do ambiente ganhou duas listas, orçamento detectado, estado de
  compatibilidade, avisos e persistência local da escolha manual.
- Adicionados testes para Qwen textual inválido, RTX de 32/4 GB, Apple Silicon,
  escolha manual e restauração automática.

## Compatibilidade

- Nenhum formato persistido existente foi removido.
- `qwenModelSelection` é aditivo e opcional para registros históricos.
- O pipeline continua consumindo `qwen-core-*` e `qwen-core-max-*`; somente os
  caminhos resolvidos passaram a refletir a seleção ativa.
