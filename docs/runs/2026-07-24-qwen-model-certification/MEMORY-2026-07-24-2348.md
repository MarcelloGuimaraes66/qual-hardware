# Memória — certificação Qwen3-VL

## Decisões permanentes

- Qwen3-VL é a única família homologada nesta entrega.
- GGUF e `mmproj` são uma unidade de certificação.
- Compatibilidade estimada nunca libera seleção.
- Hash oficial sem inferência real não basta; inferência real com hash desconhecido é somente planejamento.
- O cache dura 30 dias e qualquer mudança no stack ou ambiente o invalida.
- O hash do contrato inclui o protocolo visual completo; alterar desafio, resposta, paralelismo ou limite de tokens invalida o cache.
- Sem telemetria suficiente, usar a reserva conservadora; nunca inferir VRAM.
- Evidência anterior à calibração v7 é histórica/diagnóstica.

## Estado validado

- Windows x64 / RTX 5090: CUDA selecionado e ensaio Qwen3-VL 2B aprovado fisicamente.
- macOS arm64 e Ubuntu x64: orquestração coberta pelo servidor falso; sem aprovação física presumida.
- SQLite v13: migração aditiva e backup validados.
- Interface: teste automático dos pares Core/Core Max recomendados e teste manual dos demais.
- Portátil Windows: smoke fail-closed e smoke certificado aprovados; diagnóstico v7 físico preservou a assinatura Qwen e bloqueou aquisição.
- Encerramento abrupto: o worker cancela quando perde o coordenador e a recuperação aceita somente sidecars SQLite conhecidos vinculados ao banco registrado.
- Dependências: `npm audit --audit-level=high` validado com zero vulnerabilidades.
- Inventário Qwen: nomes persistidos aceitam separadores Windows e POSIX; o caminho local ainda precisa passar pelo ensaio funcional.
- O diagnóstico rápido físico ainda registrou RTSP como indisponível. Isso não invalida o ensaio Qwen, mas impede usar esse run como qualificação física completa.

## Próxima manutenção

- Atualizar o contrato de revisões somente com revisão imutável e OID LFS consultado na fonte oficial.
- Nova família, quantização ou projetor deve entrar como novo registro; não ampliar regex para liberar automaticamente.
- Se um driver passar a expor VRAM por processo, manter ambos os campos medidos e comparar com o fallback antes de reduzir reserva.
