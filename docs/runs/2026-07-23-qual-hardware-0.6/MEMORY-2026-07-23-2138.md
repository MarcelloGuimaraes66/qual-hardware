# Memória de engenharia

- Dimensionamento e calibração são produtos diferentes: o primeiro pode ser
  estimado por modelos técnicos; a segunda produz evidência física.
- Nunca desabilitar silenciosamente uma ação por inconsistência de formulário.
- Campos VÍDEO FULL/FRAME formam uma partição do total e devem preservar essa
  invariável a cada edição.
- `planning_only` deve mostrar números úteis e incerteza; o gate de aquisição
  continua independente.
- A quantidade informada define o projeto e a semente do ensaio, não o teto da
  busca dinâmica.
- O Codex não inicia ensaios físicos; o operador decide quando clicar.
