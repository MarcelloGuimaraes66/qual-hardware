# Memória do trabalho

Memória mantida no repositório e no contexto Codex, sem Archon.

Resultado final: a aplicação 0.6 inicia sem runtime externo, verifica o
ambiente, permite diagnóstico nativo, preserva a distinção VÍDEO/FRAME,
descobre capacidade dinamicamente, registra evidência multi-CPU/multi-GPU e
exporta PDF/TXT/XLSX/JSON e pacotes de calibração.

O benchmark genérico produz estimativa diagnóstica e nunca homologa compra. A
evidência exata depende do worker isolado compatível do Perceptrum e dos gates
físicos multi-socket/multi-GPU. O Codex não executou testes físicos.
