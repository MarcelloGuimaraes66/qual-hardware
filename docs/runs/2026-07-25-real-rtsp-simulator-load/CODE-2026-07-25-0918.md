# Código — recepção RTSP funcional

## Contratos

- Pipeline: `qual-hardware-calibration-pipeline-contract/3.0.0`.
- Kernel: `qual-hardware-calibration-kernel/5.0.0`.
- Calibração: `qual-hardware-local-calibration/8.0.0`.
- Ambiente: `qual-hardware-execution-environment/3.0.0`.
- Probe: `qual-hardware-rtsp-simulator-probe/1.0.0`.
- Evidência: `qual-hardware-rtsp-stack-evidence/1.0.0`.

O contrato v3 está em `contracts/calibration-pipeline-contract-v3.json`. O
contrato v2 não foi alterado e continua disponível para auditoria histórica.

## Implementação

- `src/server/rtspSimulator.ts`
  - descobre e identifica o executável do simulador;
  - limita a busca a `127.0.0.1`, porta 554 e 5541–5603;
  - autentica somente em memória com o contrato de teste;
  - usa RTSP/TCP, FFprobe e FFmpeg;
  - exige metadados válidos, três frames e payload elementar;
  - compara codec, resolução, FPS e bitrate com cada grupo;
  - sanitiza URLs e erros.
- `src/server/calibrationPipeline.ts`
  - faz preflight fresco antes de cada calibração;
  - prefere o simulador aprovado ao loop interno;
  - abre um leitor FFmpeg por câmera materializada;
  - mantém o loop interno exclusivamente como fallback diagnóstico;
  - mede sessões, frames, payload, latência e delta de RAM.
- `src/server/calibrationKernelWorker.ts`
  - exige `rtspQualified` para completar o pipeline técnico;
  - agrega `RtspStackEvidence`;
  - usa payload observado no estágio de rede;
  - não confunde loopback com tráfego na NIC.
- `src/shared/types.ts` e `src/shared/schemas.ts`
  - persistem contratos novos;
  - preservam leitura de calibrações v1–v7 e ambientes v1–v2;
  - impedem compra com RTSP interno, proxy, sessão incompleta ou entrega de
    frames abaixo de 99,5%.
- `src/server/executionEnvironment.ts`, `src/web/App.tsx` e
  `src/web/CalibrationResultPanel.tsx`
  - inventariam o simulador;
  - permitem localizá-lo;
  - mostram endpoints sem credenciais;
  - mostram a certificação e as métricas finais.

## Privacidade e segurança

- host, path, usuário e senha não são aceitos de JSON, API ou UI;
- a URL autenticada não é retornada nem persistida;
- `credentialsPersisted: false` é aceito pelo scanner apenas quando o valor é
  literalmente falso;
- o simulador não é iniciado, instalado ou baixado automaticamente;
- a interface alerta que o MediaMTX do simulador pode escutar em outras
  interfaces e deve ficar em rede de teste protegida.
