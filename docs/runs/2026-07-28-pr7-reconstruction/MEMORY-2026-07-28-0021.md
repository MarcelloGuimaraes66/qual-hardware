# Memória — PR legado reconstruído

1. Nunca mesclar uma branch antiga somente para fechar um PR.
2. Preservar o head original antes de reescrever uma branch pública.
3. Comparar comportamento, não apenas igualdade de patch.
4. Reaplicar somente proteções ainda ausentes na arquitetura atual.
5. Contratos e fixtures históricos não devem substituir versões posteriores.
6. `resolveCalibrationDirectory` precisa manter semântica da plataforma
   simulada, independentemente do host dos testes.
7. A atualização do mesmo PR usa `--force-with-lease` preso ao SHA revisado.
8. Archon não foi consultado nem atualizado; esta memória pertence ao
   repositório e à execução do Codex.
